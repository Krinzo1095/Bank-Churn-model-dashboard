# 📉 Churn Modeling Dashboard

An interactive Streamlit dashboard that predicts customer churn using **Logistic Regression** — helping businesses identify at-risk customers before it's too late.

## 🧠 Features

- 📊 Dataset overview at a glance
- ⚙️ Automatic preprocessing — imputation, scaling & encoding
- 🤖 Logistic Regression model with one-click **Run Model** button
- 📈 Visualizations — Confusion Matrix, ROC Curve & Probability Distribution
- 🔗 Top correlated features with the churn target

---

## 💼 Practical Use

> Churn = lost revenue. This dashboard helps businesses **spot at-risk customers early** and take action before they leave.

Whether you're in banking, telecom, or SaaS — plug in your data and get instant insights to power smarter retention strategies.

---

## 🚀 How to Run
```bash
pip install -r requirements.txt
streamlit run app.py
```
